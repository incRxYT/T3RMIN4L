Theme your terminal

A lightweight Windows app for creating, previewing, and applying stunning Windows Terminal themes with live previews, Quick Theme syntax, and backup protection built in.

Explore Features

Live Preview

See every color and background update instantly before applying changes.

Quick Theme

Create themes using clean CSS-like syntax instead of editing raw terminal JSON.

Background Support

Use PNG, JPG, or GIF backgrounds with opacity, blur, and acrylic controls.

Auto Backup

Every change is backed up so restoring a previous setup takes one click.
